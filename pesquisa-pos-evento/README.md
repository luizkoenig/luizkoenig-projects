# Pesquisa Pós-Evento — a.carol Cerimonialista

Versão visual da pesquisa do Google Forms, na identidade da a.carol
(azul `#C1D2DA`, marinho `#0F2430`, serifa + Poppins, logo e monograma AC).
Uma etapa por tela, barra de progresso, notas em botões e tela de agradecimento.

`index.html` é um arquivo único: logo e monograma já estão embutidos nele
(as cópias em `assets/` são só para referência). Para publicar no Netlify,
basta arrastar uma pasta contendo apenas o `index.html`.

## Para onde vão as respostas
Cada envio chega por e-mail em **acarolcerimonialista@gmail.com** (via FormSubmit).

**Ativação (uma vez só):** na primeira resposta enviada, o FormSubmit manda um e-mail
de confirmação para esse endereço. Clique em **Activate Form**. A partir daí,
todas as respostas chegam como uma tabela no e-mail.

Para trocar o e-mail, altere `EMAIL_DESTINO` no `index.html`.
