# Pesquisa Pós-Evento — Assessoria & Cerimonial

Versão visual da pesquisa do Google Forms: uma etapa por tela, barra de progresso,
notas em botões coloridos e tela de agradecimento. Funciona no celular.

## Para onde vão as respostas
Cada envio chega por e-mail em **acarolcerimonialista@gmail.com** (via FormSubmit, gratuito).

**Ativação (uma vez só):** na primeira resposta enviada, o FormSubmit manda um e-mail
de confirmação para esse endereço. Clique em **Activate Form**. A partir daí,
todas as respostas chegam como uma tabela organizada no e-mail.

Para trocar o e-mail, altere `EMAIL_DESTINO` no `index.html`.

## Como publicar
Qualquer hospedagem de site estático serve (GitHub Pages, Netlify, Vercel):
basta publicar o `index.html`.
