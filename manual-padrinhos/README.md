# Manual dos Padrinhos — Luiz e Thamiris

Manual para padrinhos e madrinhas seguindo a identidade visual do convite
(laranja `#E37533`, bege `#E7D7C0`, vermelho `#AA1B1B`, textura de linho,
flores secas, aquarela da igreja e a assinatura "Luiz e Thamiris").

- **Padrinhos:** terno preto, gravata cinza e camisa branca.
- **Madrinhas:** rosa, vermelho ou laranja — sem tom nem tecido definidos.

## Arquivos
- `saida/Manual_dos_Padrinhos.pdf` — PDF com as 4 páginas (1080 × 1350, mesmo formato do convite).
- `saida/manual-padrinhos-1..4.jpg` — as páginas em imagem, para mandar no WhatsApp.
- `index.html` — fonte das páginas; `figuras.js` — ilustrações em aquarela (SVG).

## Gerar de novo
```
node build.js
```
(requer Playwright/Chromium)
